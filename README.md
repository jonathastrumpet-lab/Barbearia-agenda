# Agenda Hub

Aplicativo Flutter para gerenciamento de agendas de estabelecimentos e profissionais.

## Estrutura inicial

- `lib/` — código principal do aplicativo
- `test/` — testes automatizados
- `.github/workflows/` — validação automática no GitHub Actions
- `pubspec.yaml` — dependências e metadados do projeto

## Requisitos

- Flutter SDK estável
- Dart SDK compatível com a versão do Flutter

## Como executar

```bash
flutter pub get
flutter run
```

## Como validar

```bash
flutter analyze
flutter test
```

## Próximos passos

A estrutura foi preparada para receber as telas de clientes, profissionais, serviços e agendamentos, além da configuração Android para geração de APK.
